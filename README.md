# 邰言邰语 · 生成器

同事之间图一乐的小玩具。点一下，让邰主任开口说两句。

纯静态单文件，无依赖、不联网也能跑，双击 `index.html` 即可。

## 语料的来历

从一段真实对话里把邰主任的说话骨架拆成七个槽位：

| | 槽位 | 例 |
|---|---|---|
| ① | 称呼简写 | 周校长 → **周校** |
| ② | 自贬承接 | 我也是自己瞎琢磨琢磨 |
| ③ | 遥想当年 | 遥想当年，自己在农村学校，也很想有人带领，给我支支招的 |
| ④ | 如今对比 | 如今能给你们递上一两句真心话，我也就知足了 |
| ⑤ | 感恩组织 | 很荣幸，感谢校长室给我锻炼的机会 |
| ⑥ | 平视互助 | 和年轻人相互学习，取长补短 |
| ⑦ | 情绪收尾 | 我很开心 / 我心里暖暖的 / 这就值了 |

页面底部的「邰语配方」面板把七味药材列了出来。

## 用法

- **对方是谁**：填姓名或职务，自动简写成「周校」这种叫法
- **对方说了什么**：可不填。填了会自动判断语气——表扬型／请教型／事务型／通用型，各用各的接法
- **篇幅**：短·两句 / 中·一段 / 长·全文
- **显示语气解析**：句下标注每句话的功能，说到哪句标到哪句
- 空格或 N 键 = 再来一段；生成记录点一下即复制

## 目录

```
index.html   全部内容都在这里（HTML + CSS + JS + 语料）
```

## 加语料

打开 `index.html`，搜 `邰言邰语 · 语料库`，改这几个数组就行：

`OPEN`（分工整/请教/事务/通用四种）、`MEMORY`、`MEMORY2`、`NOW`、`THANKS`、`MUTUAL`、`END`、`EMO`

注意：`MEMORY2` 是接在「遥想当年」后面往下说的续句，所以里面**不要**再出现「遥想当年」四个字，否则连着两句都这么起头会很假。
