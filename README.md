# 邰言邰语 · 生成器

同事之间图一乐的小玩具。点一下，让邰主任开口说两句。

## 两条路，自己选

| | 怎么走 | 效果 |
|---|---|---|
| **填了 Key** | 网页**直连**智谱 GLM-4-flash | 照着你那句话现写，对方说什么它看得懂；**流式**，一个字一个字往外打 |
| **没填 Key** | 网页本地拼语料 | 离线也能跑，秒出，但只会拼 |

**没填 Key 照样能用**，只是退化成"拼句子"。填了以后模型写的更活。
两条路并存：模型那边抽风了，页面自己退回本地语料，不会空着。

填 Key 就是改 `index.html` 里的 `const GLM_KEY` 那一行，没有别的步骤。

> **Key 是明文写在页面里的，谁右键"查看网页源代码"都能看见。**
> 这是权衡过的结果，不是疏忽——原方案用 Cloudflare Worker 藏 Key，
> 但 `workers.dev` 在国内被 SNI 阻断（实测 8 次连接 0 次通），
> 而智谱的 CORS 完全放开（按请求方回 `Access-Control-Allow-Origin`），
> 浏览器本来就能直连。于是砍掉中间那层，代价只剩这一条。
> 真要收紧：把 `GLM_KEY` 清空，页面立刻退回本地语料，一切照常。

## 本地跑

纯静态单文件，无依赖。双击 `index.html` 即可。

## 用哪个模型（换之前先看这节）

`index.html` 里 **`GLM_MODEL = "glm-4.5-air"`**。**换过一次，原因值得记着。**

先说速度那张表（同一把 Key、同一时刻、同样四例）：

| 模型 | 生成耗时 | |
|---|---|---|
| glm-4.5-air | 0.9 / 0.9 / 1.0 / 12 秒 | ← 当前用的 |
| glm-4-flash | 1.9 / 2.6 / 6.8 / 11.7 秒 | 原先用的 |
| glm-4.7-flash | 光排队 **84 秒** | 名字最新，免费池最挤 |

**但换掉 glm-4-flash 不是因为速度，是因为它压不住腔调。** 同一份 SKILL、同样六例对照：

| | glm-4.5-air | glm-4-flash |
|---|---|---|
| 成语味（受宠若惊／荣幸／暖暖的／无以言表） | **0 / 6** | **4 / 6** |
| 表决心（继续努力／争取…） | **0 / 6** | 1 / 6 |
| 书面腔（让我…／深感…） | **0 / 6** | 2 / 6 |

flash 是个小模型，SKILL 里"别用成语""别表决心"这几条它记不住，一放松就滑回高频词；
它还会把"被夸的人是谁"搞混（把"我"写的公开课记成"小张老师"的）。

**结论：提示词工程救不了模型太小。** 同样的 SKILL，换个大一号的模型，
三项指标直接从 4/6、1/6、2/6 落到全 0，写出来的也真是那个味道了——
"您这么说我可担当不起""能排整齐都是他们自己上心，我跟着沾了光"。
调提示词调不动的时候，先怀疑模型，别一直磨措辞。

> **注意额度：** `glm-4.5-air` 的 12,000,000 tokens 赠送包 **2026-09-28 到期**。
> 到期后落到通用的 1,919,580 tokens 那包（一次调用约 2000 tokens，够点一千来次）。
> 两个都见底了就得充值，或者把 `GLM_MODEL` 换回 `glm-4-flash`（免费，但腔调会松）。

想换模型：改 `index.html` 里的 `GLM_MODEL`，然后跑 `node worker/试模型.js 你的Key` 看哪个真能用、多快，
再跑 `node worker/试腔调.js 你的Key 模型名` 看腔调撑不撑得住。

## 腔调是怎么调出来的（三个反直觉发现）

### 一、禁词表写"哪一类不行"，别写"这几个词不行"

把"受宠若惊"点名写进禁词表，模型**照写不误**——写进提示词等于又给它复习了一遍。
改成描述类别（"全篇不用成语，四个字的那种词一个都不要"）才压得住。
教育味的意象（小树苗／沃土／耕耘者／风景）同理。

### 二、剧情骨架不能无条件套

原来的六格骨架（来路→现在→感恩→平视→收尾）是**无条件**的，结果不管对方说什么，
回话都在讲"我刚入职那会儿""遥想当年"。

对方夸的是"国旗队带得不错"，你回一段自己的来路，就是答非所问——
**同一个模子套所有事，这才是"千篇一律"的正主**（不是措辞重复，是结构重复）。

改法：SKILL 第一件事变成**判断对方话里有没有具体的事**。
有，就围着那件事说，"来路"那一格一律不用（老教师也不用，资历不是每段话都要报一遍）；
没有，才走六格。

### 三、别把旧稿摆给它看

想治"连点两次给同一段话"，试过在提示里附上刚说过的两句、要求别重样——**帮了倒忙**：
最长公共前缀从 23 字涨到 90 字，连着两次几乎一字不差。摆旧稿等于又描了一遍红。

改成**随机切口**才有用：每次从六个"从哪儿说"里抽一个（"这活儿其实是别人出力多"
"不多说事，只说心里的感受"…）。同一句"国旗队带得不错"连点三次，开头 3/3 全不同，
最长公共前缀只剩 9 个字（就是"周校，您这么一说"这半句）。

## 语料的来历

从一段真实对话里把说话骨架拆成七个槽位：

| | 槽位 | 老教师 | 新教师 |
|---|---|---|---|
| ① | 称呼简写 | 周校长 → **周校** | 同左 |
| ② | 自贬承接 | 我也是自己瞎琢磨琢磨 | 我刚入职，很多东西还在学 |
| ③ | **来路** | 遥想当年，自己在农村学校… | 回想刚入职这几个月，教案写完了都不敢交… |
| ④ | **现在** | 能尽自己的一点微薄之力 | 有师傅带着，心里踏实多了 |
| ⑤ | 感恩 | 感谢校长室给我锻炼的机会 | 感谢师傅手把手地教 |
| ⑥ | 平视 | 和年轻人相互学习，取长补短 | 以后还要多向各位老教师请教 |
| ⑦ | 情绪收尾 | 我很开心 / 这就值了 | 我很珍惜 / 心里踏实多了 |

**①⑤⑥⑦ 是这套话的"味道"，三种身份通用；③④ 是内容框架，必须跟着身份换。**

这一点是整个生成器的命门——让新教师去"遥想当年在农村学校"，一眼就假。
所以「我是谁」选的是新教师时，第三格自动换成"刚入职这几个月"。

## 用法

- **我是谁**：新教师 / 教研组长 / 老教师·师傅。决定第三、四格说什么
- **对方是谁**：填姓名或职务，自动简写成「周校」这种叫法
- **对方说了什么**：可不填。填了会自动判断语气——表扬型／请教型／事务型／通用型，各用各的接法
- **篇幅**：短·两句 / 中·一段 / 长·全文
- **显示语气解析**：句下标注每句话的功能，说到哪句标到哪句
- 空格或 N 键 = 再来一段；生成记录点一下即复制

## 目录

```
index.html          页面 + 语料 + SKILL + 生成逻辑，全在这一个文件里
                    GLM_KEY / GLM_MODEL / GLM_URL 三个常量在最上面那节

worker/worker.js    【已停用】原来的 Cloudflare 代理，代码留着备用
worker/DEPLOY.md    代理怎么部署（现在用不上了，存档）

worker/试试key.js   验一把 Key 好不好使
worker/试模型.js    几个模型挨个试，告诉你哪个能用、多快
worker/试腔调.js    拿真的 SKILL 问模型，把输出打出来，人眼判像不像

test/sse.js         单测 SSE 拆包，不需要 Key
test/e2e.js         端到端：假智谱 + 真浏览器，15 项，不需要 Key
test/real.js        真浏览器 → 真智谱，验 CORS 这条前提（会花真实调用）
```

`worker/worker.js` 和 `index.html` 现在各有一份 SKILL。**线上跑的是 `index.html` 那份**，
改腔调要改那里。worker 那份只是留着，将来若想搬回服务器（自有域名 + Cloudflare）能直接用。

三个 `worker/试*.js` 都要在 `worker/` 目录里跑，Key 走命令行参数，不落盘：

```bash
cd worker
node 试试key.js 你的Key
node 试模型.js 你的Key
node 试腔调.js 你的Key glm-4-flash
```

## 加语料（没接模型时用的那一套）

打开 `index.html`，搜 `邰言邰语 · 语料库`，结构是：

```
VOICES.rookie  /  .lead  /  .veteran
  ├ open   { praise, question, business, complain, joke, notice, general }
  │         承接对方的话，按语气分七种
  ├ aside   铺垫一句（可有可无）
  ├ memory  第三格"来路"，每个身份完全不同
  ├ memory2 接在 memory 后面往下说的续句
  ├ now / thanks / advice / mutual / end
  └ filler  口头语（说句实在话、说实话…）
```

哪些段出现、出现几段，由 `ODDS` 那张概率表定，跟着篇幅走。
短篇真的短（连"来路"和平视都可以不生），长篇六格全走。

改语料时注意五条，都是踩过的坑：

1. **感受要真，事实要留白。** 可以写"那时候条件差，什么都得自己想办法"，
   不要写"冬天教室里生个煤炉子"。越具体，当事人越一眼看出是编的。
2. **`memory2` 里不要出现 `memory` 的同款开头**（老教师那边别再写"遥想当年"，
   新教师别再写"回想刚入职"），连着两句同头很假
3. **同一格里的句子尽量错开开头。** 比如新教师的 `now` 原来 6 句里 5 句都以"现在"起头，
   撞上 `memory2` 的"现在回头看看…"就没救了——防重逻辑会退无可退，只能撞上
4. 生成器有个防同头的闸（`head2` + `pickFrom`），但它只能从你给的池子里挑；
   池子开头单一，它救不了
5. 每格会记最近用过的 2～4 句轮换，池子越小记得越少，别把某一格压到 3 句以下

改完跑 `node test/e2e.js`，看 ②（代理挂了退回本地）和 ⑤（不填代理纯本地）两路
打出来的话——这两路是它现场拼的，同头、重复、标点粘连一眼就能看出来。

## 改模型那边的腔调

`index.html` 里的 `SKILL` 那一整段，就是递给模型的"说话规矩"：
七格骨架、三种身份的来路差别、"事实留白"的铁律、不许出现的词。

改完直接 `git push`，Pages 一两分钟重建，不用再做别的。

改完记得跑一把 `node test/real.js` 看真人话——SKILL 是给模型看的，
改一个字的效果只有把输出打出来才知道。
