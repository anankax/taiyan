# 让模型开口说话 · 部署说明

网页自己不会说话，得有个中间人替它去问模型。这个中间人就是**代理**。

```
你的网页  ──►  代理（Cloudflare Worker）  ──►  智谱 GLM-4.7-Flash
（公开）        （藏 API Key 的地方）          （免费模型）
```

**为什么不能让网页直接连智谱？** 因为这站是公开的，任何人右键「查看网页源代码」就能把 Key 抄走，然后拿你的额度去跑他自己的东西。所以 Key 只能放在代理里。

整套是免费的。做完大概五分钟，一次做完所有同事都能用。

---

## 第一步 · 拿一把智谱的钥匙

1. 打开 https://open.bigmodel.cn ，注册（手机号即可）
2. 左边菜单找 **API Key**（在「财务」附近）
3. 点「新建」，起个名字随便，比如 `taiyan`
4. 复制那串 Key，长得像 `xxxxxxxx.xxxxxxxxxxxxxxxx`

> **只显示一次**，先粘到记事本上存着。丢了就删掉重建一个，不麻烦。

GLM-4.7-Flash 是长期免费的，同事几个人用，额度绰绰有余。

---

## 第二步 · 把代理挂到 Cloudflare 上

1. 打开 https://dash.cloudflare.com/sign-up ，用邮箱注册（免费，不用绑卡）
2. 登录后，左边栏点 **Workers & Pages**
3. 点 **Create** → 选 **Workers** → **Start with Hello World!**（或叫「从 Hello World 开始」）
4. 给 Worker 起个名字，比如 `taiyan`，然后 **Deploy**
5. 部署完点 **Edit code**（编辑代码），把编辑器里原有的内容**全选删掉**
6. 打开本目录的 `worker.js`，**全文复制**，粘进编辑器
7. 右上角 **Deploy**（部署）

现在你有一个网址了，形如：

```
https://taiyan.你的名字.workers.dev
```

第一次用可能需要先点一下「启用 workers.dev 子域」之类的提示，按它说的点就行。

---

## 第三步 · 把钥匙插进代理（关键）

1. 回到 Worker 的页面，点 **Settings**（设置）
2. 找 **Variables and Secrets**（变量和密钥）→ **Add**
3. 类型选 **Secret**（密钥），名字必须一字不差：

   | 字段 | 填什么 |
   |---|---|
   | Name | `GLM_KEY` |
   | Value | 第一步复制的那串智谱 Key |

4. **Save / Deploy**

> 选 `Secret` 不选 `Text`：Secret 存进去以后连你自己在后台都看不见，只能覆盖。这正是我们要的。
>
> 名字必须是 `GLM_KEY`，大小写都不能变。填错了代理会告诉你「还没配 Key」。

---

## 第四步 · 告诉网页去哪里找代理

打开 `index.html`，搜 `PROXY`，能看到这一行：

```js
let PROXY = "";   // ← 例如 "https://taiyan.你的名字.workers.dev"
```

把网址填进引号里：

```js
let PROXY = "https://taiyan.你的名字.workers.dev";
```

然后照老规矩推上线：

```bash
git add -A && git commit -m "接入模型" && git push
```

一两分钟后刷新 https://anankax.github.io/taiyan/ ，就会从「拼句子」变成「照着你那句话现写」。

---

## 怎么知道成没成

- **成了**：点「来一段邰言邰语」，按钮会变成「正 在 想 …」，等两三秒，出来一整段；句下标注是「照你这句话现写的」。
- **没成**：会弹一句提示（比如「连不上代理」），然后**自动退回本地语料**——页面永远不会空着。

想验证代理本身通不通，在浏览器地址栏直接访问那个网址，应该看到：

```json
{"error":"只收 POST"}
```

看到这行就说明代理活着。看不到（比如 404）说明 Worker 没部署成功。

---

## 平时要改什么

| 想改的东西 | 改哪里 |
|---|---|
| 说话的腔调、规矩、禁止出现的词 | `worker.js` 里的 `SKILL` 那一整段，改完在 Cloudflare 上重新 Deploy |
| 要不要用模型 / 换代理 | `index.html` 里的 `PROXY` |
| 临时换个代理试试 | 网址后面加 `?api=https://别的地址` |
| 本地那份"手搓"的语料 | `index.html` 里搜「邰言邰语 · 语料库」 |

---

## 几个坑

- **改了 `worker.js` 不重新 Deploy，等于没改。** Cloudflare 上跑的是你复制粘贴的那一份，不是本地文件。
- **`GLM_KEY` 拼错、或者填成 `Text` 类型没保存成功**，代理会返回「代理还没配 Key」。
- **代理设了限流**：每个 IP 一分钟 15 次，防的是额度被刷爆。同事正常用撞不到；真觉得紧了，改 `worker.js` 里的 `LIMIT`。
- **模型偶尔会抽风**（返回空、或者想太久超 25 秒），页面会自己退回本地语料，不用管。
- **不要把 Key 写进 `index.html`。** 这一条是底线。
